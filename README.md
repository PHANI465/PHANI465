## Recent projects

### AgentForge Sentinel · Financial investigation workbench

Reviews supported PDFs, spreadsheets, and Word documents locally in the browser, citing exact pages, cells, or document blocks. A separate investigation workbench uses synthetic transactions and requires human approval before any simulated action. I validated supported document scenarios with 24 labeled synthetic files.

**Python · FastAPI · PostgreSQL · React · TypeScript · scikit-learn**

[Try the demo](https://agentforge-sentinel.vercel.app/) · [Case study](https://phaneendragavara.dev/projects/agentforge-sentinel)

### Honest Learn · Hint-first learning app

A shared web, Android, and iOS codebase with a three-step hint ladder, parent controls, and a standalone mode that keeps data on the device. The curriculum includes 218 draft lessons across five age groups and is awaiting expert review.

**TypeScript · Expo · React Native · Hono · SQLite · PostgreSQL**

[Source](https://github.com/PHANI465/honest-learn) · [Case study](https://phaneendragavara.dev/projects/honest-learn)
